// Data privacy disclosure

What data leaves your Odoo instance.

This module connects to Atteq external servers (api.atteq.es) to fetch call data. The following data is transmitted:

  • API Token — sent for authentication.
  • Call Records — phone numbers, caller names, duration, and status.
  • Transcripts — full conversation transcripts for display in Odoo.

No internal Odoo data is sent to Atteq. Privacy policy: atteq.es/privacidad.html
